# Reference board

Created: 2026-09-08 (inferred, not viewed: no browsing of the references during the build)
Mode: Operate
Design read: personal parcel board for one owner on phone and desktop, delivery-app live-sheet lane, dials variance 4 / motion 3 / density 6 / art direction 6

## Quality bar
- Flighty (flight tracker): the arrival time is the biggest thing on screen; route line with a live position; tabular figures.
- Shop app order status: one bold "Arriving Thursday" line and a four-step bar.
- Careem / Talabat live tracking sheets: rounded bottom sheets, big ETA, stepper with checks, live dot.

## Borrow
- Palette/material: Linear-school achromatic chrome -> color only for status.
- Type/hierarchy: Flighty -> arrival line dominates, everything else quiet.
- Layout/composition: delivery-app sheets -> 20px sheets, thumb-zone composer on phones, sidebar shell on desktop.
- Motion/interaction: live tracking dot -> soft ring pulse on cards that are happening now.
- Asset language: none; drawn icons in one stroke weight.

## Avoid
- 17TRACK / Parcel-style dashboards: blue-branded chrome, equal-weight cards, tables of raw events.
- The rejected v1: kraft board, stamps, condensed uppercase type.

## Direction contract
- Thesis: arrival first; color means status.
- First viewport: phone: top bar, summary, segmented filter, arrival-led cards, bottom composer; desktop: sidebar + column.
- System: tokens in styles.css, DESIGN.md.
- Risk: reads as "another clean app" if the rail and arrival line are not kept dominant.
